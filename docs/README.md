## 🧭 核心设计原则

1. **共享 PostgreSQL 架构**：深度融入公司基础技术栈，遵循 GORM v2 标准，复用团队成熟的高可用数据库与运维备份体系。
2. **精准 Credits 算力治理**：告别粗放的请求次数限制，引入差异化 Token 费率（输入 1 / 缓存命中 0.1 / 输出 5）与模型倍率系数，日/周配额联动（周配额为日配额 4 倍）。
3. **协议感知智能直通**：保持原始载荷 100% 直通，自动探测后端对 `/v1/responses` 等协议的支持能力，严格只转发到兼容实例，杜绝 404/405 报错。
4. **生产级高可用与平滑容灾**：多后端负载均衡、主动探针、实例并发反压与默认模型自动降级（Fallback）。
5. **面向 AI Agent 深度优化**：支持 `/v1/responses` 直通端点、SSE 长连接心跳保活与 KV Cache 会话粘性亲和调度。
