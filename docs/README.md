## 🧭 设计原则

1. **极致轻量，零运维依赖**：杜绝强制引入外部 Redis、MySQL、Kafka 等复杂依赖，单个可执行文件 + 配置文件秒级拉起。
2. **生产级高可用与平滑容灾**：多后端负载均衡、主动探针、实例并发反压与默认模型自动降级（Fallback）。
3. **面向 AI Agent 深度优化**：支持 `/v1/responses` 直通代理、SSE 长连接保活与 KV Cache 会话粘性亲和调度。
4. **资产安全与成本可控**：密钥收敛、滑动窗口限流、跨午夜时段控制、全链路审计与 4 阶段原始报文转储。
