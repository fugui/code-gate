## 🧭 核心设计原则

1. **深度复用 code-common 公共框架**：直接依托 `code-common/backend`（认证、连接池、服务脚手架）与 `@code/common` 前端组件和深浅主题 Design Tokens，拒绝冗余重复造轮子。
2. **共享 CodeBench 用户，独立配额自治**：免去账号注册与密码维护成本；初次访问自动打标 **`guest`** 默认配额角色（基础体验低额度），管理员在后台灵活赋权提权。
3. **精准 Credits 算力治理**：告别粗放的请求次数限制，引入差异化 Token 费率（输入 1 / 缓存命中 0.1 / 输出 5）与模型倍率系数，日/周配额联动（周配额为日配额 4 倍）。
4. **协议感知智能直通**：保持原始载荷 100% 直通，自动探测后端对 `/v1/responses` 等协议的支持能力，严格只转发到兼容实例，杜绝 404/405 报错。
5. **生产级高可用与平滑容灾**：多后端负载均衡、主动探针、实例并发反压与默认模型自动降级（Fallback）。
